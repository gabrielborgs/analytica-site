SITE DA ANALYTICA — como publicar na Vercel

1. Crie um repositório novo no GitHub (ex.: analytica-site) e envie todo o conteúdo desta pasta.
2. Em vercel.com > Add New > Project, importe o repositório.
   Framework: Other. Build command: (vazio). Output directory: (vazio, raiz).
3. Deploy. O site fica em https://analytica-site.vercel.app (ou nome parecido).
4. Domínio próprio (quando tiver): Vercel > Project > Settings > Domains > adicionar o domínio
   e seguir as instruções de DNS no registro.br.
